# ZENVY Elite Sportswear Store

Full-stack e-commerce platform for Zenvy BD — football jerseys & sportswear.

## Tech Stack
- Vanilla HTML/CSS/JS storefront + admin panel
- Firebase Hosting + Firestore (real-time sync)
- Tailwind CSS (CDN)
- UddoktaPay bKash payment gateway
- Telegram bot order notifications

## Live Site
🌐 https://zenvy-storebd.web.app/

## Admin Panel
🔒 https://zenvy-storebd.web.app/admin.html

## Pages
- `index.html` — Customer storefront
- `admin.html` — Admin dashboard (password protected)
- `product.html` — Product detail page

## Setup
1. Clone the repo
2. Install Firebase CLI: `npm install -g firebase-tools`
3. Login: `firebase login`
4. Deploy: `firebase deploy`
